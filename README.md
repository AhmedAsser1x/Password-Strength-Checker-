# 🔒 Password Strength Checker

A modern and responsive web application that checks the strength of a password in real time.  
Built using **HTML, CSS, and JavaScript** with a clean and modern UI.

---

## 🚀 Features

- Real-time password strength detection
- Visual progress bar indicator
- Show/Hide password toggle (eye icon)
- Responsive and modern UI (glassmorphism design)
- Instant feedback for better password security

---

## 🛠️ Built With

- HTML5
- CSS3 (Glassmorphism + Animations)
- JavaScript (DOM Manipulation + Logic)
